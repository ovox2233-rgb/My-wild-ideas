# AI 小说创作知识库

个人小说创作资料库：积累写作方法、题材素材、AI 提示词，并管理每一本小说的专属资料。

## 目录导航
- [00-收集箱](00-收集箱/)：临时灵感
- [01-小说创作知识](01-小说创作知识/)：故事、人物、世界观、剧情
- [02-题材与素材库](02-题材与素材库/)：题材、人设、情节灵感
- [03-AI创作工具](03-AI创作工具/)：AI 写作和视觉提示词
- [04-创作模板](04-创作模板/)：可复制的创作模板
- [05-个人作品](05-个人作品/)：每本小说独立管理
- [99-归档](99-归档/)：暂存旧资料

## 使用方法
灵感先记入收集箱；可复用经验放入知识库；新小说复制「05-个人作品/作品模板」建立独立目录。

**原则：简单记录、持续积累；通用知识与单本小说资料分开。**
